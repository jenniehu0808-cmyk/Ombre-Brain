# rose3d — printable replica of the spiral rose

A parametric rebuild of the reference rose (cream outer petals, six black
"camera-iris" crescent petals, hexagonal centre bud, calyx, stem and leaf) as
watertight meshes for FDM printing. Everything is generated by `rose.py`; the
printed look was tuned against the reference photos with render-and-compare
iterations.

Head: 59 × 60 × 43 mm. With stem: 161 mm tall. Petals 1.2–1.5 mm thick.

## Files (`out/`)

| file | what it is |
|---|---|
| `rose_head_2colour.3mf` | **start here for a two-colour print**: cream body + black whorl already grouped as one object with colours (Bambu Studio, PrusaSlicer, OrcaSlicer open it directly) |
| `rose_head_cream.stl`, `rose_head_black.stl` | the same two bodies as STL, for slicers that want parts imported separately |
| `rose_head.stl` | the whole head as one solid body (single-colour print); 5.5 mm socket underneath for the stem |
| `rose_stem_leaf.stl` | stem (120 mm, ridged, gently curved) with a veined leaf and a peg that plugs into the head |
| `rose_all_parts.3mf` | head bodies + stem in one file |
| `rose_full.stl` | head + stem + leaf fused into one piece (not committed, ~10 MB; `python3 rose.py` regenerates it) |
| `rose_viewer.html` | interactive 3D viewer (open in any browser) |
| `rose_head_*.png`, `rose_side.png`, `compare.png` | preview renders and the comparison sheet against the reference |
| `print_report.txt` | watertightness, wall-thickness and overhang report |
| `variant_b/` | alternative head with a smoother, more ceramic-looking bowl and bolder crescents (`rose_variant_b.py`); 2-colour 3MF + previews |

## Printing

* **Head**: print face-up as exported (the flat underside sits on the bed).
  0.12–0.16 mm layers, 3 walls, 15 % infill, tree supports for the rolled petal
  rims and the undersides of the black whorl (about 3 % of the surface
  overhangs). Slow outer walls (≤ 40 mm/s), part cooling 100 %.
* **Two colours**: open `rose_head_2colour.3mf`, or import the cream and black
  STLs as parts of one object (Bambu/Orca: *Import → load as a single object
  with multiple parts*; PrusaSlicer: right-click the object → *Add part*). The
  black whorl is embedded in the cream body, so no manual painting is needed.
* **Stem + leaf**: print lying flat, leaf face up, with supports only under the
  leaf. The peg fits the socket under the head with 0.2 mm clearance; a drop of
  glue if it is loose.
* **Scale**: the model is in millimetres. Scaling the head below ~45 mm makes
  the petals thinner than a 0.4 mm nozzle likes; rebuild with `--R 22` instead,
  which keeps petal thickness constant.

## Rebuilding / changing the design

```bash
pip install trimesh manifold3d scipy pillow      # once
python3 rose.py --render                           # full-resolution build + previews into out/
python3 rose.py --R 40                             # bigger rose (80 mm head); everything scales
python3 rose.py --params my.json                   # override any LAYERS / STEM / RECEPTACLE / CORE value
./build_all.sh                                     # everything: STLs, 3MF, previews, report, viewer
python3 nesting.py                                 # radial-extent table of the petal layers
```

`rose.py` holds the flower head as parameters (`LAYERS`, `RECEPTACLE`, `CORE`,
`COLORS`): each layer is *n* petals around the axis, and each petal is a surface
in cylindrical coordinates (a Bezier centreline in the radius/height plane, an
angular width profile, cupping, imbricate spiral offset, a tapered rolled lip,
ripples) thickened into a solid by `roselib.thick_surface`. All petals are
boolean-unioned (manifold3d) into the receptacle so each colour body is one
watertight solid. `stemleaf.py` builds the stem, peg and veined leaf.
`render.js` renders previews with three.js in headless Chromium, `compare.py`
builds the contact sheet, `check_print.py` writes the print report and
`viewer_build.py` embeds the meshes into the standalone viewer page.
